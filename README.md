# Color Picker

A browser-based color picker for exploring the named CSS colors or choosing a
custom color. The app shows HEX, RGB, and HSL values, supports copying each
format, and remembers the current color in browser storage when it is available.

## Features

- Browse and select named CSS colors.
- Choose a custom color with the native color input or enter a HEX value.
- Generate a random color.
- View and copy HEX, RGB, and HSL values.
- Keep the selected color between visits using local storage.

Color selections stay in your browser; this app does not send them to a server.

## Development

```bash
npm install
npm run dev
```

## Build
